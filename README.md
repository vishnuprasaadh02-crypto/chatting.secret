## 📖 Overview

**FamWave** is a private, family-only messaging web application built with a calm ocean/water-wave aesthetic, glassmorphic UI, and comprehensive family chat capabilities. 

It is designed as a **digital living room for your household**—strictly focusing on secure, intimate family communication without social algorithms, public feeds, voice/video calls, or third-party discovery.

---

## ✨ Features

- 🛡️ **Family Gatekeeper & Login**: Enter using your secret **Family ID** and **Family Password**.
- 🔒 **Member PIN Protection**: Personal 4-digit PIN for each family member profile.
- 🌊 **Ocean Water-Wave Design System**: Interactive animated waves canvas, floating water bubbles, and frosted glass message bubbles.
- 💬 **Rich Family Messaging**:
  - Quoted replies with jump-to navigation
  - Quick emoji reactions (❤️, 👍, 😂, 😮, 😢, 🎉)
  - In-place message editing `(edited)` and deletion
  - Pinned family notices & announcements
  - `@Member` autocomplete and highlighted mentions
  - Photo sharing with fullscreen lightbox viewer
  - Document & file sharing (`PDF`, `Docs`)
  - Full-text search drawer with type filters
  - Real-time animated typing indicator
  - Online/Offline status with privacy toggle
  - Quick member switcher for instant multi-user demoing
- 📱 **Fully Responsive**: Optimized for desktop, tablets, and mobile screens.

## 🚀 Quick Start

### Option 1: Open Locally
Simply open [`index.html`](index.html) in your favorite web browser.

### Option 2: Run Local Web Server
```bash
# Using Python
python -m http.server 3000

# Using Node.js (npx)
npx serve .
```
Visit `http://localhost:3000` in your browser.
